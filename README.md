# MINIMAL

Presentation-grade fashion brand concept for MINIMAL.

## Stack

- Next.js 15
- React 19
- App Router
- CSS
- Vercel-ready

## Local development

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Structure

- `app/page.js` — interactive brand homepage
- `app/globals.css` — full-width visual system and responsive styling
- `app/layout.js` — metadata and root layout
- `public/` — campaign and product photography

Brand direction: **ONLY WHAT MATTERS.**
